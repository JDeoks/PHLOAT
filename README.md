# PHLOAT

**English** · [한국어](README.ko.md)

**Just press Space.**

Preview Markdown and code in a clear, readable format right in Finder.
Read tables and diagrams in your README, browse source code, and select and copy what you need.

<img src="assets/demo.gif" alt="PHLOAT demo" width="600">

## Installation

1. Open the downloaded DMG and drag **PHLOAT** to **Applications**.
2. Open PHLOAT once. If Quick Look is not enabled, turn on PHLOAT in **System Settings → General → Login Items & Extensions → Quick Look** (the location varies by macOS version).
3. Select a Markdown or supported code file in Finder and press **Space**.

Prefer AI setup? Give [this setup skill](skills/phloat-setup/SKILL.md) to an assistant that can run commands on your Mac and ask: “Install PHLOAT and enable Quick Look.”

## Features

- **Markdown, beautifully rendered** — Read headings, tables, checklists, and code blocks, with support for Mermaid diagrams and math equations.
- **Code at a glance** — Browse code with syntax highlighting, line numbers, and automatic line wrapping.
- **View source and copy** — Switch between rendered Markdown and its source, and copy text or code blocks.
- **Make it yours** — Choose a built-in theme or customize the colors, with support for light and dark modes.

## Supported Files

| Type | Supported formats |

| HTML | `.html`, `.htm` |

| TSX | `.tsx` |
| Python | `.py` |
